ÖNİZLEME
index.html dosyasına çift tıklayarak tarayıcıda açabilirsiniz.

GITHUB PAGES İLE ÜCRETSİZ YAYINLAMA
1. GitHub'da yeni bir repository oluşturun (ör. duringa-site).
2. Bu klasördeki index.html ve CNAME dosyalarını repository'nin ana dizinine yükleyin.
3. GitHub > Settings > Pages bölümüne gidin.
4. Source olarak Deploy from a branch seçin.
5. Branch: main, folder: / (root).
6. Yayınlandıktan sonra GitHub Pages custom domain alanında duringa.com.tr kullanın.
7. DNS tarafında web için gerekli kayıtlar daha sonra ayrıca ayarlanacaktır.
